# SPACE QUEST I: Endeavour for Opportunity

A small 2D Mars exploration game built with Python and Pygame.

## Run the game

1. Install Python 3.10 or newer.
2. From this repository's directory, install the dependency:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Start the game:

   ```bash
   python game.py
   ```

The `game.py` entry point runs the game code in `EndeavourForOpportunity`. The game can run without the optional art and sound files; it will use its built-in graphics and continue without unavailable audio. For the full presentation, keep the supplied `assets/` directory alongside these files.

## Controls

- **Enter**: start / confirm
- **H**: help or mission guide
- **Arrow keys** or **A/D**: move or select (some missions use **WASD**)
- **Space**: interact, jump, or confirm
- **Esc**: quit

More mission-specific controls are shown in the in-game help and mission screens.
